# exec/db — 스키마 덤프

| 파일 | 무엇 |
| --- | --- |
| `schema.sql` | 구조만 (`pg_dump -s`). 2026-09-23, `CREATE TABLE` 246개(파티션 포함), 444 KB |

**전체 데이터 덤프는 여기에 없다.** DB 가 약 160 GB 라 올릴 수 없다 —
이유와 대안은 [`../03_DB_덤프.md`](../03_DB_덤프.md) §1.

표본 데이터는 [`deploy/local/seed/`](../../deploy/local/seed/) 에 목적별로 다섯 벌 있다.

## 다시 뜰 때 `-s` 를 빼지 말 것

데이터까지 뜨면 수십 GB 가 나오고, 그 파일이 DB 와 같은 파티션에 쌓인다
(`/dev/root` 하나뿐). 채우면 DB 가 멈춘다. 명령은 `../03_DB_덤프.md` §3.
