# 전처리·DB 적재 안내서

`index.html`을 브라우저에서 열면 **클릭 가능한 전체 파이프라인 구조도**가 나온다.
`전처리 → 저장소 지표 연결 → 저장소 후보 선택`처럼 상자를 클릭하면 하위 처리로 들어간다.
오른쪽(모바일에서는 아래)의 패널에서 처리·입력·결과·검증·실패 시 동작을 전환한다.
경로 표시와 **상위로**, 브라우저 뒤로 가기로 돌아올 수 있다. `#map=...` 주소로 특정 처리에
바로 들어가거나 새로고침해도 같은 위치가 열린다.

**예제와 자세한 설명 읽기**는 선택한 단계의 본문을 대화상자로 보여준다.
**전체 설명서**는 기존 문서 형태로 전환한다. 기본 화면에는 전체 본문을 나열하지 않는다.
파일 하나에 데이터·스타일·그림이 포함되어 인터넷이나 개발 서버가 필요 없다.
상단 **인쇄 / PDF**로 전체 설명서를 출력한다.
실시간 서버 상태를 보여주는 화면은 아니며 구현 기준과 검증일은 첫 화면에 표시한다.

점선 밑줄 용어는 마우스를 올리거나 키보드로 포커스를 옮기면 풀이가 나온다.
모바일에서는 용어를 탭한다. 구조도 상자 안의 용어를 탭하면 풀이가 열리고,
상자의 나머지 영역이나 아래쪽 안내 문구를 누르면 하위 단계로 이동한다.
Escape 또는 바깥 클릭으로 풀이를 닫는다.

## 수정과 재생성

- `content.md`: 본문 정본. HTML을 직접 수정하지 않는다.
- `map.json`: 탐색 구조·세부 단계·5개 상세 탭·본문 연결. 실제 실행 단계와 설명용 하위 처리를 구분한다.
- `diagrams/`: 데스크톱·모바일 SVG 원본과 설명.
- `assets/reader.css`: 전체 설명서·인쇄 스타일.
- `assets/explorer.css`, `assets/explorer.js`: 노드 구조도·연결선·탐색·상세 패널.
- `glossary.json`: 용어·별칭·한국어 풀이. 새 용어는 이 파일에 추가한 뒤 다시 생성한다.
- `assets/glossary.css`, `assets/glossary.js`: 용어 자동 표시와 마우스·키보드·터치 풀이.
- `metadata.json`: 설명의 근거가 된 코드 커밋과 검토 기준일. 재검토 후 변경한다.
- `build.mjs`: Markdown과 자산을 한 HTML로 합친다.

Node.js와 **이미 설치된 marked**를 사용한다. 서비스 앱의 package.json은 변경하지 않는다.
marked가 일반 모듈 경로에 있으면 다음 명령으로 생성한다.

```sh
node docs/pipeline-guide/build.mjs
```

Codex 번들 런타임을 쓰는 Windows 환경에서는 해당 패키지 위치를 지정한다.
아래는 현재 작업 환경 예시이며 다른 PC에서는 설치 위치에 맞춘다.

```powershell
$env:NODE_PATH = "$env:USERPROFILE/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules"
node docs/pipeline-guide/build.mjs
```

본문은 저장소에서 관리하는 신뢰된 Markdown만 입력한다. HTML 상세 블록과 인라인 SVG를
허용하는 생성기이므로 외부 사용자가 제출한 Markdown의 렌더링 서비스로 사용하지 않는다.
새 의존성 설치 없이 읽을 수 있도록 생성된 `index.html`도 함께 관리한다.

## 확인

기존 Playwright와 Chrome이 있는 환경에서 아래 검사를 실행한다. Chrome 실행 파일은
`GUIDE_BROWSER`로 변경할 수 있다. 결과·화면 캡처·인쇄 PDF는 임시 디렉터리에 저장한다.

```sh
node docs/pipeline-guide/verify.cjs
```

검사 항목: 375/768/1024/1440px 너비, 구조도 넘침, 단계 클릭·하위 처리·상위 복귀,
탭과 키보드 조작, 설명 창, 뒤로 가기, 직접 주소·새로고침, 59개 항목 연결 및 본문 참조,
외부 요청, 브라우저 오류, JS 비활성 시 전체 설명서 열람, 인쇄용 출력.
용어 풀이의 열기·닫기, 모바일 폭, 설명 창 안의 표시, 복합 용어 우선 매칭과 코드 블록 제외도 검사한다.
자동 검사 외에 결과 화면을 직접 확인하고 본문의 계산·갱신·복구 설명을 코드와 대조한다.
이는 설명 문서 검증이며 파이프라인이나 운영 서버를 실행하는 검사가 아니다.
