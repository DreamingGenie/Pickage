        RailOdds 전체 경로 도착확률 및 AI 적용 설계
        1. 목표
        RailOdds는 열차 한 대의 도착시간만 보여주는 것이 아니라, 사용자가 집에서 출발해 환승
        을 거쳐 목적역에 도착할 때까지의 전체 과정을 계산한다.
        사용자에게 제공할 핵심 정보는 다음과 같다.

            지금 출발하면 목적역에 몇 시쯤 도착하는가?

            특정 시각까지 도착할 확률은 얼마인가?

            계획한 첫 열차와 환승열차를 탈 확률은 얼마인가?

            환승을 놓쳐도 다음 열차를 타고 제시간에 도착할 수 있는가?

            목표 도착확률 90%를 만족하려면 언제 집에서 나가야 하는가?

        현재 기획서의 역별 ETA 신뢰도 계산만으로는 전체 경로를 계산할 수 없다. 이를 위해 AI 지
        연 예측 모델 과 Monte Carlo 전체 경로 시뮬레이션 이 추가로 필요하다.




        2. 핵심 구조
          서울교통공사 API
          → 현재 열차 및 경로 정보 수집
          → LightGBM이 열차 지연 확률분포 예측
          → Monte Carlo가 지연시간을 표본추출
          → 집부터 목적역까지 가상 이동
          → 정시 도착확률·환승 성공확률 계산




        각 기술의 역할은 다음과 같다.

         구성요소           역할

         경로 탐색 API      출발역부터 목적역까지의 열차·환승 경로 생성

         LightGBM       현재 조건에서 열차가 얼마나 지연될지 확률분포 예측

         Monte Carlo    예측된 분포에서 값을 뽑아 전체 여행을 반복 실행

         확률 집계          목적지 도착시각과 정시 도착확률 계산

        LightGBM이 최종 도착확률을 직접 계산하는 것이 아니다.

        4.2 예측 결과
        일반적인 회귀 모델은 다음과 같이 평균값 하나를 예측한다.


          예상 지연: 45초




        LightGBM Quantile Regression은 여러 분위수의 지연시간을 예측한다.
         분위수               예측 지연

         P10               -20초
         P30               0초
         P50               +30초
         P70               +90초
         P90               +150초
        해석은 다음과 같다.

            P10: 실제 지연의 약 10%가 -20초 이하
            P50: 절반은 30초 이하, 절반은 30초 이상
            P90: 약 90%는 150초 이하
            나머지 약 10%는 150초보다 더 늦을 수 있음

        P90이 “150초 지연될 확률이 90%”라는 뜻은 아니다.
        실제 구현에서는 다음과 같이 여러 분위수 모델을 학습한다.


          P05, P10, P20, P30, P40
          P50
          P60, P70, P80, P90, P95




전체 경로 도착확률 및 AI 적용 설계                                             3
        5. LightGBM 결과를 Monte Carlo가 사용하는
        방법
        5.1 확률분포에서 지연시간 뽑기
        LightGBM은 지연 분포의 여러 지점을 예측한다.
        Monte Carlo는 0부터 1 사이의 난수를 생성하고, 해당 위치에 해당하는 지연시간을 선택한
        다.


          이번 시뮬레이션 난수 U = 0.72




        LightGBM 결과에서 P70은 90초, P90은 150초다.
        0.72는 P70과 P90 사이이므로 두 값 사이를 보간한다.

          P70: +90초
          P90: +150초
          U:    0.72


          이번 시뮬레이션 지연: 약 +96초




        TOPIS 도착예정시각이 08:10:00이라면:

          TOPIS 도착예정시각: 08:10:00
          표본추출된 지연:       +1분 36초

          가상 실제 도착시각: 08:11:36




        수식으로 표현하면 다음과 같다.


          U = 0~1 사이 난수
          지연시간 = LightGBM 분위수 분포에서 Q(U) 선택
          가상 도착시각 = TOPIS 도착예정시각 + 지연시간




        5.2 반복할 때마다 다른 값 선택
        동일한 LightGBM 결과를 사용하더라도 난수가 달라지면 시뮬레이션 결과도 달라진다.

         1               0.15              -12초     08:09:48
         2               0.42              +18초     08:10:18

        8. 열차 지연의 연속성 처리

        잘못된 방식

          A역 지연: +120초
          B역 지연: +10초

          C역 지연: +180초




        같은 열차인데 역마다 지연이 무관하게 변하는 문제가 발생한다.


        권장 방식
        현재 지연에서 다음 구간의 변화량만 예측한다.


          A역 현재 지연:      +120초
          A→B 지연 변화:      -15초
          B역 지연:         +105초


          B→C 지연 변화:      +25초
          C역 지연:         +130초




        또는 과거 열차 한 대의 전체 운행 궤적을 통째로 표본추출한다.


          train_run_id
          = 운행일 + 호선 + 방향 + 열차번호 + 종착역




        각 열차의 역별 지연 흐름을 하나의 표본으로 보관하면 동일 열차의 지연 연속성과 같은 노
        선에서 발생하는 공통 지연을 보존할 수 있다.

        14. 최종 정리
        전체 계산 과정은 다음과 같다.


          1. 경로 API가 이동 경로와 후보 열차를 찾는다.

          2. LightGBM이 현재 상황에 맞는
             열차 지연 확률분포를 예측한다.

          3. Monte Carlo가 예측 분포에서
             지연시간을 무작위로 표본추출한다.

          4. 표본추출한 지연시간으로
             첫 열차 탑승과 환승 가능 여부를 계산한다.

          5. 열차를 놓치면 다음 열차를 선택한다.

          6. 이 과정을 수천 번 반복한다.

          7. 목표 시각 전에 도착한 비율을
             최종 정시 도착확률로 제공한다.




        핵심은 LightGBM이 최종 도착시간 하나를 예측하는 것이 아니다.

        LightGBM이 열차 지연의 확률분포를 예측하고, Monte Carlo가 그 분포를 이용해 가능한
        여행 상황을 반복 실행하여 전체 경로의 도착확률을 계산한다.
