조회와 계산의 분리무거운 계산(임베딩·전이·이동쌍)은 data 노드 배치가 미리 하고, API 는 게시된 결과를 키로 읽는다.
노드 간 인계는 MinIO 객체두 노드는 서로를 호출하지 않는다. 완료 포인터를 app 노드 loader 가 읽어 게시한다.
근거 우선 AILLM 출력은 README 근거와 대조해 어긋나면 막고(502), 유사 후보는 검증된 모델만 @production 으로 쓴다.
결측을 0 으로 채우지 않음자료 없음 · 대상 밖 · 판정 불가를 data_status 로 구분해 화면이 오해하지 않게 한다.
