# 트러블슈팅 — 백신(V3)이 수집기를 중지시킨 문제

> 날짜: 2026-08-27
> 대상: 실시간 데이터 수집기(collector) 백그라운드 구동
> 한 줄 요약: **수집기를 "몰래 켜지도록" 만들었더니, 백신이 이걸 악성코드로 오해해서 꺼버렸다. "떳떳하게" 켜는 방식으로 바꿔서 해결했다.**

---

## 1. 무슨 일이 있었나

노트북에서 수집기를 24시간 백그라운드로 돌리려고 자동 실행을 설정했는데,
**AhnLab V3가 그 수집기 프로세스를 계속 중지**시켰다. 껐다 켜도 다시 죽었다.

## 2. 원래 어떻게 만들었나

처음에는 "사용자가 신경 안 써도 알아서 조용히 돌게" 하려고 이렇게 짰다.

1. 컴퓨터에 **로그인하면 자동으로** 수집기가 켜지도록 시작 프로그램에 등록
2. 그때 **까만 창(콘솔)이 안 보이게 숨겨서** 실행
3. 수집기가 꺼지면 **자동으로 다시 켜지도록** 반복 실행
4. 수집기는 켜져 있는 동안 **바깥(교통 API 서버)으로 주기적으로 계속 접속**

편하게 쓰라고 넣은 기능들인데, 하필 이 조합이 문제였다.

## 3. 왜 V3가 막았나 (쉽게 비유하면)

위 4가지를 사람 행동으로 바꿔보면 이렇다.

- 주인 몰래 **뒷문으로 들어와서** (숨겨서 실행)
- **알아서 눌러앉고** (로그인 시 자동 시작)
- 쫓아내도 **계속 다시 들어오고** (자동 재시작)
- **바깥에 계속 신호를 보낸다** (주기적 외부 접속)

이건 사실 **악성코드(바이러스)가 하는 짓과 똑같다.** 악성코드도 몰래 깔려서,
자동으로 살아나고, 외부 서버로 정보를 계속 빼돌린다.

V3에는 "행동을 보고 판단하는 기능"(행위 기반 탐지)이 있다. 파일 이름이나
내용이 아니라 **"이 프로그램이 지금 뭘 하고 있나"**를 본다. 우리 수집기는
하는 짓이 악성코드와 판박이여서, V3 입장에선 **막는 게 정상**이었다.
즉 V3가 오작동한 게 아니라, **우리가 악성코드처럼 보이게 만든 것**이다.

## 4. 어떻게 원인을 확인했나

말로만 추측하지 않고 두 가지를 비교해봤다.

| 실행 방식 | 결과 |
|---|---|
| **숨겨서 자동으로** 켜기 (원래 방식) | 켜지자마자 죽음 — 아예 시작조차 못 함 |
| **창을 띄우고 직접** 켜기 | 정상 작동, 데이터도 잘 수집됨 |

똑같은 수집기 코드인데, **"어떻게 켜느냐"에 따라** 하나는 죽고 하나는 살았다.
그래서 코드 자체가 아니라 **"몰래 켜는 방식"이 문제**라는 게 분명해졌다.

## 5. 어떻게 해결했나

교훈은 하나였다 — **숨기려고 할수록 백신과 계속 싸우게 된다.**
그래서 "더 잘 숨기는" 대신, **의심받을 이유 자체를 없앴다.**

악성코드처럼 보이게 만든 3가지 신호를 전부 제거했다.

| 없앤 것 | 바꾼 방식 |
|---|---|
| 창을 숨김 | **창을 보이게** 띄운다 (최소화는 해도 됨) |
| 자동 실행 프로그램으로 위장 | **사용자가 직접** 실행 파일을 켠다 |
| 로그인 시 몰래 자동 시작 | 자동 시작을 **떼어냄** |

결과적으로 수집기는 이제 **"사용자가 직접 연 평범한 프로그램"**이 되었다.
사람이 직접 켠 프로그램의 자식은 V3가 거의 건드리지 않는다. 실제로 바꾼 뒤
V3에 걸리지 않고 정상 수집됐다.

실행 방법도 단순해졌다.

- `collector/scripts/run_collector.cmd` 파일을 **더블클릭**하면 켜진다.
- 까만 창이 하나 뜨는데, **최소화**해서 두면 된다. (닫으면 수집이 멈춘다)
- 멈추려면 그 창에서 `Ctrl + C`.

## 6. 그래도 또 막히면 — 근본 해결책

주기적으로 외부에 접속하는 것 자체는 수집기의 본질이라 없앨 수 없다.
그래서 V3가 나중에 또 반응할 수도 있다. 그럴 때의 **확실한 해결책은
"이 프로그램은 안전하다"고 V3에 직접 등록**하는 것이다(예외 등록).

- V3 → 환경설정 → PC 보안 → 검사 예외 설정
- `C:\git\S15P21A506` 폴더를 예외에 추가

이건 **보안 설정을 바꾸는 일**이라 사용자가 직접 해야 한다. 회사 지급 장비라
예외 등록이 막혀 있으면, IT 담당에게 "교통 공공데이터를 수집하는 프로그램"
이라고 용도를 설명하고 요청하면 된다.

## 7. 교훈

- **"편하게 자동으로"가 항상 좋은 건 아니다.** 숨기고 자동화하는 순간,
  백신 눈에는 악성코드와 구분이 안 된다.
- **백신과 싸우지 말고, 오해받을 짓을 안 하는 게 답이다.** 떳떳하게(보이게,
  사용자가 직접) 실행하면 대부분 해결된다.
- 완전한 해결은 **예외 등록**이다. 다만 이건 보안 설정이라 사용자·IT의 몫이다.
