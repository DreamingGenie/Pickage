## 1. 범위와 용어

- 분석 대상은 npm 패키지다.
- **기준 패키지**는 비교의 출발점이며 보고서 배열의 첫 번째 패키지다.
- **비교 패키지**는 기준 패키지를 포함해 최소 1개, 최대 3개다.
- **관측된 이동 경로**는 두 패키지가 같은 publisher-month에 빠지고 들어온 통계이며 인과를 뜻하지 않는다.
- **기능 비교**는 선택한 버전의 메타데이터와 문서 근거로 생성한 RAG 결과다.
- **완료**는 기준점 코드에 구현됨을 뜻하며 운영 서버의 당일 정상 상태까지 보증하지 않는다.

## 12. 오류·빈 상태 계약

- 검색 결과 없음과 서버 오류를 구분한다.
- 후보가 없어도 직접 추가 경로를 제공한다.
- 한 패키지의 지표가 없어도 다른 패키지 결과는 유지한다.
- RAG 문서가 없으면 `DOC_NOT_FOUND`, 출력 검증 실패는 명시적 실패로 처리한다.
- 커뮤니티 수집 중에는 마지막 snapshot과 갱신 상태를 구분한다.
- 출력물은 빠진 섹션을 조용히 삭제하지 않고 이유를 적는다.
