## Status meanings

- `FIXED`: PM/제품 원칙으로 고정
- `VERIFIED`: 실제 데이터/실험으로 확인
- `TO_VERIFY`: 핵심 Spike 필요
- `CONDITIONAL`: 조건 충족 시 채택
- `HOLD`: 아직 결정하지 않음
- `DROP_MVP`: MVP에서 제외
- `BLOCKED`: 외부 요인(승인/등록 등)으로 진행 불가, 코드 문제 아님
