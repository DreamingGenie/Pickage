직접 수정한 기존 이슈는 85건(업무 제목 79건·에픽 분류 안내 6건)이다. 에픽 제목 수정 요청은 3건이다.

Jira 변경 이력과 이번 실행의 수정 필드를 대조했다. 사용자는 이후 직접 변경한 것이라고 확인했다.

- 이력에서 시작일 변경도 확인했지만 전체 최초 조회의 시작일 필드는 없으므로 시작일 전수 불변을 주장하지 않는다.
- 사용자 변경 14개 비교 필드를 명시적으로 분리했다. 전체 관측 변경은 90개 이슈지만 이번 에이전트 수정은 85개 이슈다.
