# 불필요 파일 정리·검수 기록

> 작업일: 2026-09-23
> Jira: `S15P21A506-473`
> MR: `!277`

## 1. 정리 원칙

파일명이나 확장자만으로 삭제하지 않았다. 다음 조건을 모두 만족할 때 삭제 대상으로 판정했다.

1. Git이 추적하는 파일이다.
2. 현재 코드·문서·빌드·테스트에서 참조하지 않는다.
3. 제품 자산, fixture, 검증 evidence, 실행 ledger, history 보관본이 아니다.
4. 삭제해도 원천 정보나 재현 근거를 잃지 않는다.
5. 사용자가 제거 대상으로 명시했거나 재생성 가능한 임시 산출물임이 확인된다.

로컬 ignore 파일과 cache는 사용자의 작업 상태이므로 이번 MR에서 삭제하지 않았다.

합계 2개, 555,909 bytes를 Git 추적 대상에서 제거했다. 두 파일은 커밋 `e9d1bb3`에서 함께 들어왔고
이후 변경·참조 이력이 없었다.

## 3. 재발 방지

루트 `.gitignore`에 다음 규칙을 추가했다.

```gitignore
/Claude outputs/
```

같은 이름의 로컬 출력 폴더가 다시 생겨도 `git add .`에 섞이지 않는다. 실제 제품 이미지나 검수
evidence는 각각 `frontend/public/`, `docs/worklogs/*/evidence/`처럼 목적이 드러나는 위치에 둔다.

## 4. 조사했지만 유지한 항목

| 후보 | 유지 이유 |
| --- | --- |
| `.claude/settings.json` | Claude Code 커밋 attribution 설정으로 도구 동작에 쓰임 |
| `frontend/public/` 로고·아이콘·폰트 | 제품 런타임·브랜딩 자산 |
| `backend/src/main/resources/fonts/` | PDF 한글 렌더링에 필요한 런타임 자산 |
| `docs/history/**` 로그·이미지·PDF | 폐기·교체된 주제의 원문과 검증 evidence |
| `docs/worklogs/**/evidence/` 로그·이미지·JSON | 구현·성능·검수 결과의 재현 근거 |
| `pipeline/collectors/bigquery/ledger/*.log` | 수집 회차·파일 무결성 추적 ledger |
| 빈 `__init__.py` | Python package·상대 import 구조 유지 |
| `.gitkeep` | 의도한 빈 데이터 디렉터리 구조 유지 |
| `datasets/**` 대용량 CSV | 각 README와 빌더가 참조하는 현재 데이터 계약·표본 |

특히 `history`와 `worklogs`는 현재 런타임에서 참조되지 않는다는 이유만으로 삭제하지 않았다. 이
폴더들의 목적은 실행이 아니라 결정·검증 이력 보존이다.

## 5. 검증 결과

- 삭제 전 두 PNG 모두 Git 추적 확인
- 파일명·폴더명에 대한 저장소 참조 0개 확인
- 삭제 후 `Claude outputs/` 디렉터리 없음
- 삭제 후 해당 경로의 Git 추적 파일 0개
- `.gitignore` probe가 루트 규칙에 일치
- 삭제 용량: 555,909 bytes
- `git diff --check` 통과
- 삭제 대상은 바이너리 PNG뿐이며 코드·설정·데이터 파일 변경 없음

README 작업 직후 같은 브랜치에서 프런트 168개, AI/RAG 247개, 백엔드 Gradle 검증을 통과했다.
이번 추가 변경은 참조되지 않는 이미지 삭제와 ignore 규칙뿐이므로 동일 테스트를 다시 실행하지 않고
참조·추적·diff 검증을 수행했다. MR CI가 전체 변경을 다시 검증한다.

## 6. 복구 가능성

파일은 Git 커밋 이력에 남아 있어 필요하면 `e9d1bb3`에서 복구할 수 있다. 로컬 휴지통으로 이동한
것은 아니며 이번 브랜치에서 Git 삭제로 기록했다.

## 7. 결론

추가 삭제 근거가 확실한 파일은 `Claude outputs/`의 PNG 2개뿐이었다. evidence·history·ledger와
런타임 자산은 목적을 확인하고 유지했다. 이번 정리는 저장소 용량보다도 생성 도구의 임시 결과가 제품
자산처럼 루트에 남는 구조를 제거하고 재발을 막는 데 목적이 있다.
