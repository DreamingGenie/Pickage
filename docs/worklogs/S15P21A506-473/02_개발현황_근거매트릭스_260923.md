## 6. 재현 명령

```bash
git log --oneline 2c9c791..c88e20a
git branch -r --no-merged origin/develop
rg -n "@GetMapping|@PostMapping|@RequestMapping" backend/src/main/java
rg --files backend/src/main/resources/db/migration
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run test
npm.cmd run build
backend/gradlew.bat test
python -m pytest ai
python -m pytest pipeline
```

마지막 `pipeline` 일괄 명령은 성공 명령이 아니라 현재 collection 문제를 재현하는 명령이다.
파이프라인의 개별 모듈별 테스트 방식과 CI 보강은 README 정리·후속 기술 작업에서 다뤄야 한다.
