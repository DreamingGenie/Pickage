## 3. `frontend/docs/` 로컬 스냅샷 2개 파일 처리

`git log --follow`로 확인한 결과 `frontend/docs/OSS_Shift_기능별_개발구상안_0902.md`·
`OSS_Shift_메뉴구조_IA_0902.md`는 최초 프론트 레포 구축 커밋(`a360602`, `S15P21A506-261`)에서
0902 세트를 그대로 복사해 들여온 뒤 한 번도 갱신되지 않은 **로컬 벤더 사본**이다
(`docs/history/0907_260902_oss_shift_final_set_archive/`의 같은 이름 파일과 내용이 이 사본의
출처로 보인다). 이 사본을 계속 유지하면 이번처럼 다시 뒤처지는 문제가 반복된다.

**결정**: 두 파일을 삭제하고, `frontend/CLAUDE.md`·`intro-content.ts`의 참조를 루트
`../docs/Pickage_*_0910.md`로 직접 가리키게 한다. 루트 `docs/README.md`가 이미 "현행 문서" 단일
포인터 역할을 하고 있으므로(팀 관례), 프론트가 별도 사본을 유지할 이유가 없다.
이 판단은 사용자(PM)가 다른 방식을 원하면 되돌릴 수 있는 가역적 변경이다 — 되돌리려면
`git show a360602:frontend/docs/...`로 복원 가능.

기능적 참조(코드 import 등) 여부는 저장소 전체 grep으로 확인했으며, 두 파일을 가리키는 것은
`frontend/CLAUDE.md`(경로 서술)와 `intro-content.ts`(주석 1줄)뿐이다 — 실행 코드에서 파일을
읽어오는 import/require는 없다.
