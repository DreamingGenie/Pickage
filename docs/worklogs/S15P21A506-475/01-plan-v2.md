## 2. 공통 금지·원칙

1. 운영 쓰기는 단계마다 승인 + 컨트롤 타워 확인. 한 번에 하나.
2. 쓰기 전 **이전 상태를 파일로 저장**(포인터 JSON, 테이블 백업, 이미지 태그). 저장이 없으면 시작하지 않는다.
3. 배치 중에는 `deploy-ai`·`deploy-app` 머지 금지(README 규칙).
4. 운영 DB 에 전수 스캔 조회를 던지지 않는다(1d 에서 60초 타임아웃 4건 발생).
5. 비밀값은 출력하지 않는다. `.env` 는 키 이름과 허용 목록 값만.
6. 수치는 증거 파일과 함께만 보고한다. 추정은 [추정] 으로 표시한다.
