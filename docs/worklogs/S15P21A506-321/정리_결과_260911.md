## 결론

기존 234건을 대조했다. 미착수 107건(에픽 8, 일반 업무 99)의 분류를 정리했고,
진행 중 15건·완료 112건은 직접 수정하지 않았다. 제목 변경 35건(에픽 8·일반 27),
에픽 이동 47건, 분류 대상 107건의 라벨 정리를 확인했다. 신규 생성은 제품 에픽 5건과
이번 정리 추적 작업 321 한 건이다. 이슈 삭제·재생성, 기존 상태 전이, 기존 담당 재배분은 없다.

## 계획 평가와 적용

1. 기능 에픽·업무 성격 접두사·파트·개인 담당을 분리했다. 부서별 에픽 추가는 하지 않았다.
2. 기존 키와 이력 보호를 위해 FE/AI 에픽을 삭제하거나 다른 제품 기능으로 재사용하지 않았다.
3. 모든 확장을 하나의 에픽에 두던 114에서 독립 제품 범위를 분리했다. 공통 성능 검증과 진행 중 교체 흐름은 남겼다.
4. 공통 에픽 소속만으로 하위 업무를 MVP로 바꾸는 오류를 계획 검수에서 차단했다. 250은 [확장] 유지.
5. 파트는 Component 대신 라벨로 적용했다. 현재 도구에는 Component 생성·보드·자동화 설정 기능이 없다.
6. 308에 제목·에픽·라벨을 시험 적용하고 Bug 유형·담당·상태·에픽 링크 동기화를 확인한 뒤 확대했다.
7. 대상 상태·제목·에픽을 재조회하고 승인 범위만 수정했다. 최종 전체 재조회에서 보호 필드를 비교했다.
