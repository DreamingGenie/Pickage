# S15P21A506-278 — 다운로드 원본 보관과 스냅샷 구간 집계

보유한 npm 일별 다운로드 데이터를 검증해 원본 그대로 보관하고, 스냅샷 기준일 사이의
다운로드 합계를 만들어 후속 패키지 지표 적재에 제공하는 작업이다.

| 작업 | 입력 → 출력 | 현재 상태 |
| --- | --- | --- |
| 다운로드 원본 검증·Bronze 입고 | 보유 CSV·원본 응답·일별/상태 Parquet → MinIO `pickage-raw`의 검증된 원본과 실행 기록 | 구현·전체 입고·재검증 완료, 커밋 `a173015` |
| 스냅샷 구간 다운로드 집계·Curated 게시 | 승인된 원본·스냅샷 기준일·패키지 목록 → `pickage-curated`의 패키지별 구간 합계와 품질 정보 | 계약·작업 계획 작성 완료, 구현·실행 미착수 |
| PostgreSQL `package_snapshot` 통합 적재 | 다운로드 구간 합계 등 지표 → 조회용 DB 행 | 별도 후속 작업, 이 티켓 범위 밖 |

Bronze는 검증한 원본을 보관하는 영역이고, Curated는 집계·가공한 결과를 보관하는 영역이다.
manifest는 한 실행이 사용하거나 생성한 파일 목록·크기·해시·검증 결과를 담는 명세다.
스냅샷 구간은 이전 기준일 P부터 현재 기준일 S 직전까지의 `[P,S)`다. 일부 날짜가 누락돼도
유효 값의 부분합을 게시하고, 합산한 일수와 누락 사유를 함께 제공한다.
