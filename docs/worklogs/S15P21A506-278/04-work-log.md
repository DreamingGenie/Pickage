시각은 실제 실행 또는 결과 확인 시각이며 원본 파일의 생성·수집 시각이 아니다.
W-001~003은 전날 착수 기록이고, 구현·데이터 검증·MinIO 작업은 W-004부터 수행했다.
원본 API 재수집, 로컬 원본 변경, PostgreSQL 적재·스키마 변경은 수행하지 않았다.

W-005·006의 독립 조사 결과와 본 실행의 최종 manifest는 확인 시점과 코드 구성이 다르다.
후속 인계에는 READY 요청 범위 집계와 730개 물리 스키마 검사를 포함한 최종 manifest를 사용한다.
W-009·010의 증거는 [Bronze 실행 요약](evidence/bronze-load.json),
[입력 품질 요약](evidence/source-summary.json), [계보 요약](evidence/lineage-summary.json)에 보관했다.
기존 객체 보존 검사는 키·크기·ETag·수정 시각의 비교이며, 이전 3,927개 객체 전부의 바이트를
이번에 다시 읽었다는 의미는 아니다. 새 선택 입력 768개는 두 시도 모두 전체 원격 바이트를 대조했다.
문서·증거 검사는 [최종 검사 기록](evidence/documentation-check.json)에 남겼다.
