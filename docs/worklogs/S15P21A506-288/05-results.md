출처는 [다운로드 결과](../S15P21A506-278/08-interval-results.md)와
[선행 입력 기록](evidence/input-handoff.json)에 기재한 저장소 지표 증거다.
선행 생산 모듈의 테스트 통과 건수를 이 티켓에서 실행한 테스트 수로 합산하지 않는다.

V-007의 83개는 이번 병합 코드에서 새로 실행한 검증이다. 추가 18개는 같은 테스트의 줄바꿈
보정 후 재확인으로, 서로 다른 테스트가 101개라는 의미는 아니다. Spark 13개는 고정 이미지의
격리 컨테이너에서 실행했고, 나머지는 기존 `.venv-bq`와 소형 fixture·가짜 MinIO로 실행했다.
MinIO 게시·실제 PostgreSQL 검증은 V-002 이후 단계에 남아 있다.

## 실제 실행 뒤 추가할 결과

통합 run ID·manifest SHA·정책/코드 해시·출력 목록, DB execution/attempt ID·대상·상태,
원천별/통합/DB 행 수, 중복·누락·FK·지표 값 불일치, NULL 사유·부분합·실제 0 건수,
소요 시간·사용한 환경, 같은 입력 재실행과 실패 복구·보존 결과를 기록한다.
직접 확인할 SQL은 실제 컬럼과 실행 ID를 기준으로 작성하고 결과를 함께 남긴다.

운영 DB 이관·백엔드 애플리케이션 기동·API 검증·전체 과거 기간 적재·원격 Jira 변경은 미실행이다.
