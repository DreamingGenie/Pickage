ISS-010은 코드 내용이나 해시 계산 알고리즘을 바꾸지 않고 이번 병합에서 달라진 줄바꿈만 복원했다.
공통 모듈의 줄바꿈은 변경하지 않았다. 원본 `repository_metrics/__init__.py`의 마지막 빈 줄 1개는
승인 코드 해시를 보존하기 위해 유지했다. 기본 `git diff --check`의 해당 경고는 원래 커밋에도
있으며, 이 한 가지를 제외한 공백 검사는 통과했다.

## 기록할 때 주의할 점

선행 다운로드 결과는 COMPLETE 97,091행과 PARTIAL 637행이다. 합계가 있는 행은 둘을 합친
97,728행이므로 COMPLETE 건수만을 유효 합계 전체로 기록하지 않는다. 부분합을 NULL로
바꾸거나 다운로드의 NULL 때문에 저장소 지표를 함께 지우지 않는다.

두 지표 모두 NULL인 저장소 결과도 승인 패키지 행이다. 지표를 갖는 패키지만 INNER JOIN하면
전체 대상이 줄어들므로 승인 모집단을 기준으로 결합한다. 예상 밖 행 누락은 정상적인 값의
NULL과 구별하여 실패로 처리한다.

이후 이슈에는 발견 시각·재현 조건·원인·수정 내용·재검증 근거를 추가한다.
계약을 문서에 적은 것과 해당 코드·테스트가 완료된 상태를 구분한다.
