## 이번 단계 착수 시 정한 변경 범위

입력은 기존 7번 run 위치에서 읽기 전용으로 조사하고, 승인 여부와 별개인 입력 조사 증거를 이 폴더에 남기기로 했다. 원본 파일 이동·복사와 완료 marker 생성은 제외했다. 기존 DuckDB로 작은 정답 그래프의 집계 핵심과 실패 경계를 구현·검증하고, 생산용 입력 검증·전체 파일 게시·DB 적재는 후속 단계로 구분했다. 실제 수행 결과는 W-006~008에 기록했다.

현재 조사에서 준비 단계 candidates가 최종 stable-semver target 모집단과 같지 않다는 점을 확인했다. 조회한 패키지에 한정된 target_quality를 전체 후보 검증으로 해석하지 않고, 실제 전체 target 모집단의 검증·확정은 별도 선행 조건으로 남긴다.

W-001~004는 문서 준비 단계이며 링크·형식·변경 범위 점검 결과는 [V-001](05-results.md)에 기록했다. 이 단계에서는 구현 코드·서비스 DDL·기존 작업 기록·원본 데이터를 변경하지 않았고, 계산·DB 적재·commit·push를 수행하지 않았다. 이후 구현 진행은 W-005부터 구분해 기록한다.

## 이후 기록 형식

각 작업은 단계 또는 이슈 ID, 실제 변경 파일, 실행한 검증과 결과, 증거 위치를 함께 남긴다. 실패도 삭제하지 않고 후속 조치와 연결한다. 오래 걸리는 실행은 시작·중단·재개·종료 시점을 구분하고, 프로세스 실행 중이라는 관측을 완료 결과로 적지 않는다.
