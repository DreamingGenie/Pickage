## 3. 전처리 전에 알아야 할 것

### 3-1. 미존재 781개 — 0이 아니라 없음

npm API가 모르는 이름(unpublish·삭제): 스코프 404 + 비스코프 377. `downloads_status.status = 'NOT_FOUND'`. 순위표의 `status` 열(removed/unpublished 4,373개)과 부분 겹침. **행이 없는 것이지 0이 아니다.** 화면 상태 `NOT_FOUND`로 표시하고 다음 주 갱신 큐에서 뺀다.

### 3-2. 결손일 — API는 결손을 0으로 준다

| 날짜 | 전체 합계 | 판정 |
|---|---:|---|
| 2026-07-12 (일) | **0** (99,215개 전부 0) | npm 전체 결손 |
| 2026-08-14 (금) | **0** (전부 0) | npm 전체 결손 |
| 2026-07-09 (목) | 18.3bn (요일 중앙값 32.3bn의 57%) | **부분 결손** |
| 12-24 ~ 01-02 (두 해 모두) | 요일 중앙값의 30~60% | 결손 아님, **연말 계절성**. 그대로 둔다 |

적용한 규칙(`to_parquet.py`): `downloads = 0`이고 전후 7일 중앙값 ≥ 1,000이면 NULL + `imputed_gap`. 437,786행(0.7%)이 바뀌었고, 두 전체 결손일은 규칙이 전부 잡았다. **부분 결손일(07-09)은 0이 아니라 절반 값이라 규칙에 안 걸린다.** 일 단위 지표를 쓰려면 07-09를 별도 예외 목록으로 두거나, 주 단위 합계로 리샘플해 희석시킨다(권고: 주 단위).

### 3-3. 요일 효과 — 주말은 평일의 40~45%

2026년 평균 일 합계(단위 10억): 월 26.4 · 화 28.0 · 수 27.6 · 목 26.5 · 금 23.1 · **토 11.3 · 일 11.0**. 다운로드는 CI·개발자 근무일에 좌우된다. **일별 값을 그대로 추이 그래프에 올리면 톱니만 보인다.** 7일 이동합 또는 주(월~일) 단위 리샘플이 기본이고, 비교는 같은 요일 구성으로 한다(계획 §6 "주 단위 리샘플, 이동평균"과 일치).

### 3-4. 분포 — 극단적 롱테일

| 지표 (최근 30일 합계 기준) | 값 |
|---|---:|
| 상위 1,000개의 점유율 | **57.1%** |
| 상위 10,000개의 점유율 | 96.4% |
| 패키지별 30일 합계: p10 / 중앙값 / p90 / p99 / 최대 | 13.7천 / 80.1천 / 4.55M / 210M / 3.46bn (semver) |

로그 스케일이 필수다. 화면에서 두 패키지를 나란히 놓을 때 절대값보다 **정규화(자기 최댓값 대비, 또는 주간 증감률)**가 맞다.

### 3-5. 저빈도·신규·소멸 패키지

| 항목 | 패키지 수 | 비율 | 전처리 시사점 |
|---|---:|---:|---|
| 0인 날이 50% 이상 | **9,300** | 9.4% | 추이 계산 시 0 다수 → 이동평균·증감률이 불안정. 최소 활동 기준(예: 30일 합계 ≥ 1,000) 아래는 "표본 부족" 표시 |
| 첫 다운로드가 2025-09-01 이후 | 10,170 | 10.3% | 신규 패키지. 이력 12개월 미만 → "전년 대비" 불가 |
| 최근 30일 합계 0 | 19 | 0.02% | 사실상 소멸. 순위표(ecosyste.ms last-month)와 어긋남 |
| 패키지별 0 비율: 중앙값 1.1% · p90 45% · p99 93% | | | 0은 대부분 진짜 0(소형 패키지). 5,317,162행(8.5%)이 0으로 남아 있음 |

### 3-6. 이름 — 대소문자 39개

`Faker`, `jxLoader`, `CETEIcean`, `canvas-toBlob` 등 39개는 npm 초기의 대소문자 이름이다. npm은 대소문자를 구분하므로 **소문자로 정규화하면 다른 패키지와 충돌**할 수 있다. deps.dev `PackageVersions.Name`과 조인할 때 원문 그대로 exact match로 한다.

### 3-7. 순위표와의 정합성 — 좋다

ecosyste.ms 순위(last-month)와 우리 8월 합계 순위의 상관 **0.995**. 상위 1,000개 중 우리 순위 5,000 밖으로 밀린 것은 0개. 대상 선정 기준이 실제 트래픽과 어긋나지 않는다.

### 3-8. 시간 축 주의

- 일자는 **UTC**. KST 화면의 "이번 주"와 하루 어긋난다.
- 마지막 날(2026-08-31)의 값은 안정적이다(요일 패턴에 맞음). 갱신 시 구간 끝은 실행일 −2일(UTC)로 유지.
- 2024-09 ~ 2025-02는 비스코프만 있으므로 **전체 합계 추이는 2025-03부터** 그린다.
