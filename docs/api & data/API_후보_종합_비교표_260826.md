# API 후보 종합 비교표

> 작성 기준: 2026-08-26 KST
> 대상: `docs/api & data/`의 2026-08-25 분석 문서 19건 + `DECISION_SHEET_260824_v0.2.md`에 기록된 route provider 후보 3건
> 목적: feature 착수 전 후보 API를 한 장에서 비교하고 착수 순서를 정하기 위한 인덱스

## 읽는 법

- **시점** — `정적`(버전 단위로만 갱신), `과거`(집계 주기 명시), `실시간`(호출 시점 스냅샷). 포털의 `실시간` 라벨이 아니라 각 분석 문서가 실제 데이터로 판정한 값이다.
- **활용 가능성** — 이 표를 작성하며 내린 **종합 판정**이며, 각 분석 문서의 개별 판정과 다를 수 있다. 다를 경우 `근거·조건`에 문서 판정을 함께 적었다. 기준은 아래 두 축의 결합이다.
  - 데이터 자체가 두 제품 기능(`출발 시간 추천` / `도착 가능성 계산`)에 기여하는 정도
  - 지금 실제로 접근 가능한지(키·승인·네트워크)
- **높음** = 접근 경로가 확인됐고 기여도가 분명함 / **보통** = 가치는 있으나 선행 조건이 남음 / **낮음** = 현재 막혀 있거나 기여도가 제한적

## 공통 이슈

### 1. `openapi.seoul.go.kr:8088` 접근 차단

서울 열린데이터광장 Open API의 upstream 호스트가 **TCP 연결 단계에서 차단**된다(15~21초 timeout). 클라우드 세션과 조사자 로컬 PC 양쪽에서 15개 케이스로 확인됐다. 호스트:포트 단위 차단이라 서비스와 무관하게 적용된다.

| 영향 | 대상 | 현재 상태 |
|---|---|---|
| **우회 가능** | OA-12913, OA-12252, OA-12928, OA-15262, OA-12034 | 443 포트 **파일 다운로드**로 대체 성공 |
| **우회 불가** | OA-13291, OA-13315, OA-22718 | 실시간 API라 파일 대체 경로 없음 — 현재 사용 불가 |
| **영향 없음** | OA-12764, OA-15799, OA-12601 | 호스트가 `swopenAPI.seoul.go.kr`로 다름 |

**SSAFY 교육망 방화벽 여부를 확인해야 한다.** 교육망 문제면 배포 환경에서 풀리므로 도로·알림 계열 3종을 살릴 수 있고, 아니면 Leave-now의 도로 context feature를 범위에서 제외해야 한다.

### 2. 지하철 전용키 1,000회/일

인증키 1개당 1일 1,000회이며 계정 단위 공유 한도다(활용사례 갤러리 등록 시 무제한 전환 가능, 현재 미등록). 120초 폴링이면 720회로 하루치가 겨우 들어간다. **역별 API(OA-12764)를 주 경로로 쓰면 역 수만큼 곱해져 즉시 초과**하므로, 일괄 API(OA-15799) 단독 폴링 + 역별 API 보조가 사실상 유일한 설계다.

### 3. 백필 깊이 게이트

날씨-지연 상관분석은 러시아워 강수 표본이 필요한데, 순방향 수집만으로는 마감(2026-09-25)까지 **≥1mm 러시아워가 약 6시간**뿐이다. T-DATA-1068이 공개일(2021-12)까지 열리면 약 260시간으로 성립한다. **1068의 최초 조회 가능 `stdrDe` 확인이 이 연구 전체의 선행 게이트다.**

지하철 쪽은 OA-12252가 139개월을 즉시 제공해 이 게이트를 이미 통과했다.

## 착수 순서 제안

| 순서 | 작업 | 이유 |
|---|---|---|
| 1 | `openapi.seoul.go.kr:8088` 차단이 교육망 문제인지 확인 | 비용 10분, 도로·알림 3종의 생사가 갈림 |
| 2 | T-DATA-1068 활용승인 + 최초 `stdrDe` 조회 | 버스 historical과 날씨 상관분석이 동시에 걸려 있음 |
| 3 | 정적·이력 파일 6종 적재기 (OA-12252 / 12913 / 22522 / 12034 / 22521 / 15262) | 승인·네트워크와 무관하게 지금 착수 가능 — 1·2번 대기 중 병렬 진행 |
| 4 | 실시간 수집기 (OA-15799 / OA-12601 / getBusPosByRouteSt / getArrInfoByRouteAll) | 접근 검증 완료. quota 설계(공통 이슈 2)를 먼저 고정 |
| 5 | 날씨·도로 feature (ASOS → 초단기실황, T-DATA-1015) | 교통 파이프라인이 선 것을 전제로 함 |

OA-12252 수집기는 **`(사용월, 호선명, 지하철역)` 유니크 제약을 먼저 넣고** 시작한다. 없으면 최신월이 2배로 적재된다.
