## 이 package에 포함된 text_extracted

PDF를 VS Code에서 빠르게 grep/search할 수 있도록 `pdftotext -layout`으로 추출한 `.txt`도 함께 제공한다.  
이는 원본 PDF의 편의용 파생물이며, 레이아웃/표/그림 의미가 중요할 때는 반드시 원본 PDF를 확인한다.
