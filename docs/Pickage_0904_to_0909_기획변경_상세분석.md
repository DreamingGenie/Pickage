## 결정 1 — GitHub 커뮤니티 패키지 선택 단일화 (`DEC-COMMUNITY-20260909-01`, `S15P21A506-284`)

**무엇이 바뀌었나**: 커뮤니티 현황(확장-03)이 "비교 대상 중 저장소 연결이 검증된 첫 패키지"를
자동 선택하던 것에서, "사용자가 최초 입력한 기준 패키지 하나"만 분석하는 것으로 바뀌었다. 기준
패키지의 저장소가 미검증이면 다른 비교 패키지로 대체하지 않고 제공 불가 상태만 표시한다.

**왜 바뀌었나**: 이 기능은 팀원이 아직 못 챙긴 확장 범위를 담당자가 단독으로 먼저 개발하는
것이라, 여러 후보 중 검증된 것을 자동으로 대신 보여주는 원래 설계 대신 사용자가 실제로 분석하려던
패키지 하나만 다루는 단순한 계약을 택했다.

## 결정 2 — Spring→GMS 직접 호출 예외 명시 (`DEC-COMMUNITY-20260909-01`, `S15P21A506-284`)

**무엇이 바뀌었나**: 개발 구상안 §3.2/§3.8에 "GitHub 커뮤니티 확장(확장-03)의 refresh 경로에 한해
Spring Boot가 bounded 실행 단위로 GMS(외부 LLM 요약) API를 직접 호출한다"는 예외 조항을 추가했다.
나머지 v1 서빙 경로(카드·비교·유사 후보·보고서 API)는 "PostgreSQL 조회 전용" 원칙을 그대로 유지한다.

**왜 바뀌었나**: 이 확장 기능을 담당자가 단독으로 미리 개발하는 상황이라, 팀의 서빙/배치 분리
원칙에 새 배치 노드나 별도 worker를 두는 대신 Spring 내부의 제한된 실행 단위로 처리하는 것이 현실적인
예외라고 판단했다. 이는 재작성이 아니라 각주 추가다 — 기존 "PostgreSQL 조회만 수행" 원칙 자체는
그대로 남는다.

## 결정 3 — 후보 ranking: deprecated 완전 제외, top-K/Recall 20으로 하향 (`DEC-RANK-20260909-01`, `S15P21A506-285`)

**무엇이 바뀌었나**: `DEC-RANK-20260907-01`이 deprecated 패키지에 "지목 가산"(점수 가산)을 주던
것을, 코퍼스 자격 필터 단계에서 완전히 제외하는 것으로 바꿨다. `top-K 50`은 `top-K 20`으로,
`Recall@50`은 `Recall@20`으로 하향했다. `Recall@10`·MRR 등 재랭킹 이후 지표는 변경하지 않았다.

**왜 바뀌었나**: deprecated 패키지는 이미 서비스가 종료된 패키지이므로 비교 후보로 추천되면 안
된다는 판단이다. 기존 티켓 `S15P21A506-172`("제외 규칙(자기자신·폐기·버전미확정) 구현하기")도
이미 폐기 제외를 전제하고 있어, 이번 정정은 문서를 그 기존 티켓 의도에 맞춘 것이기도 하다.

| 문서 | 위치 | 0904 | 0909 |
|---|---|---|---|
| 기능별 개발 구상안 | §1.3/§4.1 코퍼스 필터 | deprecated 여부 태깅 | deprecated 제외(자격 미달로 처리) |
| 기능별 개발 구상안 | §1.3/§4.1/§4.2 top-K | top-K 50 | top-K 20 |
| 기능별 개발 구상안 | §1.3/§4.1/§4.2/§4.2.1/§3.5 | Recall@50 | Recall@20 |
| 기능별 개발 구상안 | §4.2 재랭킹 규칙 | 가산: deprecated 지목 | (가산 항목 삭제, drop에 deprecated 포함) |
| 서비스 기획서 · 요구사항 명세서 | `DEC-RANK` 인용 전체(용어·원칙·기능-03-R03 등) | `deprecated 지목 가산` 포함, `DEC-RANK-20260907-01` | `deprecated 지목 가산` 삭제, `DEC-RANK-20260909-01` |

**유지된 것**: `deprecated 51K 홀드아웃` 평가셋 크기, `Recall@10`/MRR, 3계층 코퍼스→top-K→재랭킹
구조 자체는 그대로다. 홀드아웃 셋은 deprecated 패키지를 질의(X)로 써서 실제 후계 패키지가 결과에
있는지 측정하는 용도라 후보 코퍼스에서 deprecated를 제외하는 정책과 충돌하지 않는다.
